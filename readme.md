### Sobre este desafio
Neste desafio o objetivo é consolidar os fundamentos do Spec Driven Development, criando uma constituição, especificação, planejamento e tarefas manualmente para serem implementadas pela IA posteriormente.

#### O que foi implementado
- Encurtador de links através da criação dos arquivos .md para implmentação utilizando SDD por IA.

Neste processo eu aprendi:
* ✅ a importância do passo a passo da estruturação dos arquivos e pelo que cada arquivos é responsável.
* ✅ me fez relembrar sobre análise de requisitos e o quanto essa prática é importante para entregar um software de qualidade.
